# 渲染层 (Rendering Layers) 验证手册

## 准备

1. 场景里放一个 `Plane`（地面）、几个不同颜色的 `Cube/Sphere`
2. 新建一个 `ArgonaraRenderPipelineCamera` 组件挂在主相机上（稍后用）
3. 确保 `PostFXSettings` 已挂好（Bloom 的 `downscaleLimit ≥ 1`）

---

## 2.1 — Light Culling Mask 警告

**原理**：SRP 下 Light 的 Culling Mask 只影响阴影，不影响光照。Inspector 里如果改了，黄色警告提醒你。

**验证步骤**：
1. 场景里放一个 Directional Light
2. 选中它，Culling Mask 默认是 **Everything**
3. 改成 **Nothing** → 应该出现黄色警告框：`"Culling Mask only affects shadows."`
4. 切换灯光类型为 Point/Spot → 警告变为 `"...unless Use Lights Per Objects is on."`
5. 改回 Everything → 警告消失

---

## 2.2 — Light 端 Rendering Layer Mask 修复 + 阴影层剔除

**原理**：Unity 自带的 Light 组件 Rendering Layer Mask 选框选了不生效（bug），我们修了。同时开启了 `useRenderingLayerMaskTest`，阴影会按渲染层剔除。

**验证步骤**：
1. 选中场景里的 Directional Light，找到 **Rendering Layer Mask** 下拉框
2. 会看到**两个同名的下拉框**——上面是 Unity 原生（有 bug），下面是我们修的（多一个 tooltip `"Functional version of above property."`）
3. 在**我们修的下拉框**里，只勾选 **Layer 1**
4. 把所有物体（Cube/Plane）的 MeshRenderer → **Rendering Layer Mask** 也设为 **Layer 1**
5. 确认阴影正常
6. 把一个 Cube 的 Rendering Layer Mask 改为 **Nothing**
7. 那个 Cube **不投阴影了** ✅

---

## 2.3 — 掩码传到 GPU / 灯光过滤

**原理**：物体的渲染层掩码存在 `unity_RenderingLayer.x`，灯光的塞在 `_DirectionalLightDirectionsAndMasks.w`。shader 通过 `RenderingLayersOverlap` 位与判断该光是否照亮该物体。

**验证步骤**：
1. 用两个不同颜色的 Point Light（或 Spot Light），一个设置 Rendering Layer Mask = **Layer 1**，另一个 = **Layer 2**
2. 场景里放两个 Cube：Cube A 设为 Layer 1，Cube B 设为 Layer 2
3. 运行后：
   - Cube A 只被 Layer 1 的灯光照亮
   - Cube B 只被 Layer 2 的灯光照亮
4. 验证方式：关掉一个灯，另一个灯只能照亮对应层的物体

---

## 2.4 — Int → Float 位重解释

**原理**：`light.renderingLayerMask` 是 `int`（位掩码），GPU 数组只能传 `float`。C# 用 union struct（`StructLayout.Explicit`）让 int 和 float 共享同一块内存，位模式原样传递，不破坏掩码。

**验证步骤**：无需单独验证。只要 2.3 的验证通过（灯光正确过滤），就证明掩码传递正确。如果掩码被破坏，你会在物体上看到毫无规律的灯光行为。

---

## 2.5 — 相机 Rendering Layer Mask

**原理**：每台相机通过 `ArgonaraRenderPipelineCamera` 组件获得自己的 Rendering Layer Mask 下拉框，传递到 `FilteringSettings(renderingLayerMask:)`——相机只渲染选定层的物体。

**验证步骤**：
1. 场景里建两个 Cube，MeshRenderer → Rendering Layer Mask 分别设为 **Layer 1** 和 **Layer 2**
2. 主相机的 `ArgonaraRenderPipelineCamera` 组件上，把 **Rendering Layer Mask** 设为 **Layer 1**
3. 运行 → 只能看到 Layer 1 的 Cube，Layer 2 的消失了 ✅
4. 改为 Everything → 两个都看到 ✅

---

## 2.6 — 相机端灯光屏蔽

**原理**：相机可选 `maskLights`，进一步按渲染层过滤**灯光**，让同一场景在不同相机下看到不同光照。

**验证步骤**：
1. 场景里放一个 Directional Light（Rendering Layer Mask = Layer 1），一个 Point Light（Rendering Layer Mask = Layer 2）
2. 所有物体的 MeshRenderer → Rendering Layer Mask 设为 **Everything**
3. 主相机 `ArgonaraRenderPipelineCamera` 组件：
   - **Rendering Layer Mask** = Layer 1
   - 勾选 **Mask Lights**
4. 运行 → 只有 Directional Light 生效（灯光层匹配相机层）
5. 取消 **Mask Lights** → 两个灯光都看到 ✅
