## 大规模重构：法线贴图 + InputConfig + 可选贴图开关
- **Common.hlsl**: 添加 `DecodeNormal()`, `NormalTangentToWorld()`, 引入 `Packing.hlsl`
- **Surface.hlsl**: 添加 `interpolatedNormal` 字段（原始插值法线，用于阴影偏移）
- **Lit.shader**: 添加 `_NORMAL_MAP`, `_MASK_MAP`, `_DETAIL_MAP` toggle 属性，法线贴图属性
- **LitInput.hlsl**: 引入 `InputConfig` 结构体（baseUV, detailUV, useMask, useDetail），所有 getter 函数改为接收 InputConfig，添加 `GetNormalTS()`, `_NormalMap`, `_DetailNormalMap` 支持
- **LitPass.hlsl**: 适配 InputConfig，添加 tangent 支持，条件编译 `_NORMAL_MAP`、`_DETAIL_MAP`
- **Shadows.hlsl**: `GetCascadedShadow` 使用 `surfaceWS.interpolatedNormal` 做阴影偏移
- **ShadowCasterPass/MetaPass/UnlitPass/UnlitInput**: 适配新的 InputConfig 函数签名

## Occlusion 处理
- 用户将 occlusion 的 lerp 从 `lerp(occlusion, 1.0, strength)` 改为 `lerp(1.0, occlusion, strength)`，使其语义更直觉：strength=1 = 完全AO效果
