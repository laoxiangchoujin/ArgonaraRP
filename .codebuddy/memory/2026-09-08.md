## 渲染管线 - 定向光级联阴影扩展到 8 级（Shadows 重构）
- 背景：用户自定义 SRP（类 Catlike），想把定向光级联从 4 扩到 8。引擎 API `ComputeDirectionalShadowMatricesAndCullingPrimitives` 因 splitRatio 是 Vector3 只支持 ≤4 级，故采用文章 B 的自定义函数 `ComputeDirectionalShadowMatricesAndCullingSphere`（相机视锥包围球 + LookAt 正交投影），已植入 `Shadows.cs`。
- 布局方案：图集按"每灯一行、每级联一列"长方形布局；`atlasWidth = cascadeCount*tileSize`，`atlasHeight = 灯数*tileSize`；tile 保持正方形 2 的幂；图集宽高动态按实际灯数/级联数算，不浪费。
- 关键改造点（均已完成）：
  - `Shadows.cs`：`maxCascades = 8`；`Setup` 增加 `Camera camera` 参数（由 CameraRendererForward/Deferred → Lighting.Setup 传入）；新增两个 `SetTileViewport` 重载（旧的给 other 光、新的 4 参给方向光）；`ConvertToAtlasMatrix` 拆 scaleX/scaleY 两个版本；`cascadeRatios` 越界保护 farRatio/nearRatio（7 个值合法，末级自动到 1）。
  - `Shadows.hlsl`：`MAX_CASCADE_COUNT 4→8`；新增 `_OtherShadowAtlasSize`；`FilterDirectionalShadow` 组装 `(1/宽,1/高,宽,高)` 适配长方形；`FilterOtherShadow` 改用 `_OtherShadowAtlasSize.yyxx`。
  - `ShadowSettings.cs`：`cascadeRatios` 改数组，默认 `{0.05,0.1,0.2,0.35,0.5,0.65,0.8,1f}`；保留旧 `atlasSize` 死字段（可删）。
- 同步规则（以后改级联数需三者一起加）：CPU `maxCascades`、GPU `MAX_CASCADE_COUNT`、`cascadeRatios` 长度。
