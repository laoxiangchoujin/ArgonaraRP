## 📖 读了用户给的两篇（`毅毅_SSR_精简版.txt`、`毅毅的HiZ的文章部分.txt`）要点

- **Hi-Z 步进（原文）**：屏幕空间 DDA（沿主轴每步 `stride × 2^mip` 像素）→ 采**该级一格** → 远点越过表面（`rayFarZ <= surfaceZ`）时：
  **mip0 且 `abs(surfaceZ - rayNearZ) < thickness` ⇒ 命中**；**否则"位置退回一步 + mip−1"**（原文：高层级被遮挡先回溯、再小步迈进，直到回到第 0 层）；
  没越过 ⇒ `mip = min(mip+1, _MaxHiZMipLevel)`（步长翻倍）。
- **起点沿法线抬起 `rayOffset`（0.01 量级）**（治自交；太大 ⇒ "钳制范围"，太小 ⇒ 自反射）。
- **近平面截断**（`endVS.z > -near ⇒ 截短 maxDistance`）—— 两位作者都踩过这个坑。
- **出屏必须检查**（否则 Clamp 采样 ⇒ "拉丝"）。
- **⚠️ 调参坑（原文原话）**："我们的步长 Stride 和阈值 Thickness 都将使用**更高的参数**……如果使用原来的值会出现**非常严重的断层**。"
- **Hi-Z 图**：单通道 `R32_SFloat`；**各层尺寸取"大于屏幕的 2 的整数次幂"**（原文理由：准确对齐屏幕信息、提高降采样准确性）；6 级；
  用 **`FilterMode.Bilinear`** 的 RT（采样用 `sampler_HiZTex` = 带采样的 sampler）；采样时按**任意步位置**直接采该级。
- 命中判据与 Thetus / 毅毅三篇互相印证：**"远点已越过表面 && 近点深入不超过厚度"**（我们 `intersect` 就是这个 ✓）。
- 屏幕边缘衰减用**"暗角"式**（`pow(saturate(1 - att²), 5)`，椭圆）比方形取大者更像暗角。
- 作者列的后续方向：glossy 多光线 / **CameraColor 生成 mip 用距离当 mip（= 我们的 roughness→mip ✓ 已有）** / 半分辨率（✓ 已有）/
  Planar Reflection Probe 兜底 / Temporal Filter / Motion Vector（"法线高频时转镜头就闪"）/ TAA。

## 🔍 我们现在的 Hi-Z 代码 vs 它：差异 / 未实现（= TODO，按影响排序）

1. **Hi-Z 下要有单独的 stride / thickness（且更大）**：我们 Hi-Z 的基准步长**写死 1 像素**、thickness 与线性版**共用** `_SSRPixelThickness`（0.15 m）。
   作者明确说 Hi-Z 下这两个都要明显更大。⇒ 加 `hizStride`、`hizThickness` 两个旋钮。
2. **Hi-Z 各层尺寸改成 2 的整数次幂**：我们是屏幕尺寸（1920×1080）⇒ 1080 的 mip 从第 3 级起是 135/68/34…（奇数）
   ⇒ 每级"2×2 块"的对齐会有半纹素误差 ⇒ 采样到的格子不完全对应屏幕块（**很可能就是"按格排布的小三角/梳齿"的来源之一**）。

5. **Hi-Z 采样方式**：我们用 `sampler_point_clamp` + **两个抽头取更近**（更保守）；
   原文用 **bilinear sampler 在任意步位置采一格**（更平滑、更少硬边）。⇒ 可试 bilinear。

     `float3 rayStartVS = startVS + normalVS * _SSRRayOffset;`
     之后 `startSS` / 近平面截断（`rayStartVS.z`）/ `endVS` / `start1bz` **全部改用 `rayStartVS`**。
  3. **删掉 `inSelfBand`**：原来"起点深度带内一律当空、不判命中"那条补丁（连带 `float startZ`）整段删除，

- **风险/看什么**：① 主目标 = **物体根部和倒影是否接上了**（缝是否消失）；② 有没有**新的自反射**（起点抬得不够）——
  太小就往上调；③ 有没有"**钳制范围**"那种怪东西（起点抬太大）—— 太大就往下调；④ 根部的"白点/频闪"有没有回来。

## 📐 TODO ④ 的"怎么改"（2026-09-21 给用户解释过，等他点头再动）

**它那套**（原文）：`rayNearZ/rayFarZ` = **相邻两个中点**的深度（不是步子两端）；判据 =
`rayFarZ <= surfaceZ`（中点已越过面）**且** `abs(surfaceZ - rayNearZ) < thickness`（上一个中点离面不超过一个厚度）
⇒ 语义 = "**这一步跨过了这个面**"（前后各留一个厚度容差）。注意它和我们**线性版**的 `intersect` 是同一句（文章自己说"完全相同"）。
**我们 Hi-Z 现在**：前门用步子**末端**（`rayFarZ > surfaceZ`），命中窗口锚在**采样点**、**单边**（`sampleZ > surfaceZ && surfaceZ > sampleZ - thickness`）
⇒ 语义 = "**采样点已经钻进面里、且不超过一个厚度**" ⇒ 采样点一步迈进面里更深时就整条丢掉（掠射/大梯度处 ⇒ 漏）。
**改法（一次一处）**：
1. 循环里维护 `prevMidZ`（上一轮的 `sampleZ`）；
2. 前门/降档判据从 `rayFarZ > surfaceZ` 改成 `sampleZ > surfaceZ`（都锚到中点，口径统一）；
3. 命中判据换成原文那句：`sampleZ > surfaceZ && abs(surfaceZ - prevMidZ) < thickness`；
4. 风险：命中变**容易** ⇒ 可能出现假命中/"反射粘在物体上"，安全阀仍是 `thickness`（调小更严）。

  （他先 `currPosSS += dPosSS*exp2`，再算 `currInvW + 半步` 当 far）⇒ 它的"采样点越过" = **未来那一点**越过 ⇒ 保守；
  而我们是在这一步的**中点**采样（**落后半步**）⇒ 同一句话变成"当前中点正越过" ⇒ **步末那段还没测就把整步放行** ⇒ 一步跳过去 ⇒ 条纹。
  ⇒ **两边的 near/far 定义整体错开半步，判据不能逐字抄。**
- **已修的版本（现在这一版）**：
  1. **门回到"这一步的远端"**：`if (rayFarZ > surfaceZ)`，其中 `float rayFarZ = max(1.0/current1bz, 1.0/next1bz);`
     （原来那段"rayNearZ/rayFarZ + Swap 排序"已删，改成 max，更直白也消掉一个未用变量警告）；
  2. **命中窗口**（= ④ 的本意）：`if (abs(surfaceZ - sampleZ) < _SSRPixelThickness)`
     ⇒ "面落在**采样点 ± 一个厚度**之内（前后都算）" —— 门已保证"远端越过" ⇒ 合起来就是"**这一步跨过了这个面**"；
     窗口**没有**撑大到整步的深度跨度 ⇒ 掠射处不会到处假命中；
  3. `prevMidZ` 那套**整个删掉**（不再需要）。
- 教训：**"照抄原文判据"之前先核对"采样点/步进的时间对齐"**（原文是"先迈半步再判"，我们是"中点采样、判两端"）。
