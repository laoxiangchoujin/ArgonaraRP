# 2026-07-27 工作日志

## Lit Shader GUI 重构（已实现）

四文件改动：`Assets/ArgonaraRP/Shaders/Lit.shader`、`LitInput.hlsl`、`LitPass.hlsl`、`Assets/ArgonaraRP/Runtime/Editor/ArgonaraShaderGUI.cs`。**未动** `CameraRendererPasses.hlsl`（延迟光照 pass），仅先在 forward 测试。

### 最终确认的关键决策
- 命名用 `_Clipping`/`_CLIPPING`（修正原 `_AlphaCutoff`→`_Cutoff`，并修好原 `_ALPHA_CLIP` 与 pragma `_CLIPPING` 不匹配的 bug）。
- **保留 `base.OnGUI`**：只把用户明确要求分组的内容用 `DrawGroups()` 手动绘制，`FilterHiddenProperties` 仅隐藏这些已分组属性；其余（含将来新增）属性仍由 `base.OnGUI` 自动显示。
- Mask 单张通道 = **R=Roughness, G=Metallic, B=Occlusion**（用户指定 RMO 组合）。
- 分开三张贴图：`_MetallicMap`/`_OcclusionMap`/`_RoughnessMap`，均取 `.r`。
- `_Smoothness` 保留；mask 激活时 `smoothness = 1 - roughness`，否则用 `_Smoothness` 滑块（向后兼容）。
- 关键词：`[KeywordEnum]` 属性名 `_Mask_Map` → 精确生成 `_MASK_MAP_NONE`/`_MASK_MAP_SINGLE`/`_MASK_MAP_SEPARATE`；Emission 用 `[Toggle(_EMISSION)]`。两 Pass (前向+GBuffer) 的 `#pragma` 已同步加上述关键词。
- Detail Mask 新增 `_DetailMaskMap`（默认 white），采样 baseUV 取 `.r`，取代原 `GetMask(c).b` 当 detail mask 的用途。
- Stencil：`_StencilRef`(0)/`_StencilComp`(Always=8)/`_StencilOp`(Keep=0)，SubShader 级默认 no-op；GUI 用折叠栏。

### 改动要点（落地）
- LitInput：删 `GetMask`/`useMask`；`GetMetallic/Occlusion/Roughness` 按 mask 模式分支；`GetSmoothness` 在 mask 模式走 `1-roughness`；`GetEmission` 包 `#if _EMISSION`；新增 `GetDetailMask`；cbuffer `_AlphaCutoff`→`_Cutoff`、新增 `_Roughness`、新增分离贴图与 `_DetailMaskMap` 纹理声明。
- LitPass：删两处 `config.useMask`；`_ALPHA_CLIP`→`_CLIPPING`。
- GUI：`OnGUI` 先 `DrawGroups()` 再 `base.OnGUI(filtered)`；新增 `DrawHeader/DrawProperty/IsOn/DrawGroups`；`BakedEmission` 移入 Emission 组；`FilterHiddenProperties` 改为 HashSet 隐藏已分组属性。
- Shader Properties 重排 + Stencil 块。

### 注意事项
- 旧 `.mat` 文件（如 `Catlike_Scene8/mat_circuit*.mat`）仍带失效的 `_MASK_MAP` 关键字与 `_MaskMapToggle` 属性，需在新 GUI 下重新设置 Mask 模式。
- 延迟路径（GBuffer）已同步 pragma，但延迟光照 `CameraRendererPasses.hlsl` 未改，待用户 forward 测试通过后再验证 deferred。
