## 渲染缩放后处理 Rescale + Bicubic Rescaling（Catlike 教程）
- 讨论 Scaled Post FX：DoBloom 改用 bufferSize（而非 camera.pixelWidth）计算金字塔尺寸；bloomResultId 保持全分辨率（与 source 合成需同分辨率）。prefilter 仍半分辨率，二者分辨率级别从未改变，只是尺寸基准从物理像素换成 bufferSize。
- 实现 Rescaling in LDR：render scale≠1 时 DoColorGradingAndToneMapping 走 else 分支——Pass.Final 在 bufferSize 尺寸做分级+tone mapping 写入 `_FinalResult` 临时RT（LDR），再用 Pass.FinalRescale 把 LDR 缩放到屏幕。先分级后缩放，避免 HDR 插值锯齿与色带。
- 实现 Bicubic Rescaling：CameraBufferSettings.bicubicRescaling → Setup 参数 → shader `_CopyBicubic` → FinalPassFragmentRescale 走 GetSource(双线性)/GetSourceBicubic(双三次)。
- Debug 黑屏：shader 的 Final Rescale pass 写 `#pragma fragment CopyPassFragmentRescale`，但 hlsl 定义的是 `FinalPassFragmentRescale`，名字不匹配导致该 pass 编译失败、scale≠1 时黑屏。已改为一致。佐证：scale=1(走 Pass.Final)正常，scale≠1(走 FinalRescale)黑屏。

## 关键认知
- `Shader.PropertyToID` 产生的 RT 名（如 `_FinalResult`）只是 C# 端句柄，shader 不认；shader 通过 `SetGlobalTexture(_PostFXSource, rtId)` 复用既有全局纹理通道读取。
- shader `#pragma fragment` 函数名必须与 hlsl 定义精确一致，否则该 pass 编译失败、对应分支黑屏。
